
论文阅读报告


一、引言

1.1 研究背景

后量子密码学的迫切需求

2024年8月，美国国家标准与技术研究院（NIST）正式发布首批后量子密码标准，包括基于格的ML-KEM（密钥封装）、ML-DSA和SLH-DSA（数字签名）。这一里程碑标志着密码学界进入"后量子迁移"时代。然而，NIST明确指出，这些标准并非最终方案，仍需持续评估替代技术。在此背景下，基于同源的密码学（Isogeny-based Cryptography）因其独特的安全特性而备受关注。

同源密码学的核心优势在于：目前尚无已知的量子算法能在多项式时间内求解超奇异椭圆曲线同源问题。这与基于格的方案形成对比——后者虽能抵抗已知量子攻击，但其安全性基于启发式假设（如Ring-LWE、Module-LWE的困难性）。同源问题的数学基础更为经典，与椭圆曲线密码学（ECC）有深厚渊源，但又能天然抵抗Shor算法攻击。

SQIsign的特殊地位

SQIsign由De Feo等人于2020年提出，是唯一进入NIST第二轮评估的同源数字签名方案。其核心优势在于极短的签名长度（约200字节，与ECC相当），但代价是计算效率低下——签名和验证需要昂贵的理想-同源转换。这一瓶颈催生了SQIsignHD、SQIsign2D-West/East等一系列变体，而本文的SQIsign2D2代表了该家族的最新进展。

1.2 论文核心贡献

Xu等人提出的SQIsign2D2通过重新设计素数参数和创新算法架构，实现了迄今最快的SQIsign2D变体：

指标	SQIsign2D-East	SQIsign2D2	提升	
密钥生成时间（NIST-I）	560 ms	213 ms	2.63×	
签名时间（NIST-I）	1263 ms	587 ms	2.15×	
验证时间（NIST-I）	296 ms	247 ms	1.20×	
签名大小（压缩版）	9λ bits	9λ bits	持平	

关键创新在于利用一维光滑同源（power-smooth isogenies in dimension one）大幅降低二维同源的计算开销，体现了"降维攻击"的算法设计思想。

二、技术背景

2.1 超奇异椭圆曲线同源基础

定义2.1（同源）设E_1, E_2为定义在\mathbb{F}{p^2}上的椭圆曲线，同源（isogeny）\varphi: E_1 \to E_2是满足\varphi(\infty) = \infty的非恒定有理映射。若\varphi可分，则\#\ker(\varphi) = \deg(\varphi)，称为n-同源。

Deuring对应是连接同源与四元数代数的核心桥梁：

\{\text{超奇异椭圆曲线}/\cong\} \longleftrightarrow \{\text{最大序的左理想类}\}

具体而言，给定超奇异曲线E满足\text{End}(E) \cong \mathcal{O} \subset B{p,\infty}（B{p,\infty}为在p和\infty处分歧的四元数代数），则：
- 同源\varphi: E \to E'对应左\mathcal{O}-理想I\varphi
- \deg(\varphi) = \text{Nrd}(I\varphi)（理想的简约范数）
- 复合同源对应理想乘法

计算瓶颈：理想-同源转换（Ideal-to-Isogeny Translation）需要将四元数理想中的元素显式计算为曲线上的有理映射，这是SQIsign家族的核心效率瓶颈。

2.2 高维同源与Kani引理

定理2.2（Kani引理，[23]）设A, B为互素整数，D = A + B。给定同源图：

\begin{array}{ccc}
E_0 & \xrightarrow{\psi} & E_1 \\
\downarrow{\varphi} & & \downarrow{\varphi'} \\
E_2 & \xrightarrow{\psi'} & E_3
\end{array}

其中\deg(\psi) = A, \deg(\varphi) = B, \psi' = [\varphi]\psi, \varphi' = [\psi]\varphi，则映射

\Phi = \begin{pmatrix} \psi & -\hat{\varphi}' \\ \varphi & \hat{\psi}' \end{pmatrix}: E_0 \times E_3 \to E_1 \times E_2

是(D,D)-同源（二维同源），其核为\{([B]P, \theta(P)) \mid P \in E_0[D]\}，其中\theta = \psi' \circ \varphi = \varphi' \circ \psi。

算法意义：Kani引理允许通过二维同源计算来分解和求值一维同源，这是SQIsignHD和SQIsign2D家族的技术基础。

2.3 SQIsign2D-East协议框架

作为对比基准，简述SQIsign2D-East的识别协议：

阶段	操作	
Setup	素数p = 2^{a+b}f - 1 \approx 2^{2\lambda}，初始曲线E_0: y^2 = x^3 + x	
KeyGen	随机N\tau-同源\tau: E_0 \to E_A，N\tau < p^{1/4}为素数且\left(\frac{3}{N\tau}\right) = -1	
Commit	随机N\psi-同源\psi: E_0 \to E_1，N\psi < 2^{a+b} \approx \sqrt{p}	
Challenge	验证者发送K{\text{cha}} \in E_1[2^b]	
Response	计算挑战同源\varphi: E_1 \to E_2，构造响应同源\sigma: E_A \to E_2使得\deg(\sigma) = q为(2^a, 2^b)3-nice	
Verify	通过(2^a, 2^a)-二维同源验证\sigma的存在性	

(2^a, 2^b)3-nice的严格定义（[11]修正后）：
1. q为奇数
2. q < 2^a
3. q(2^a - q) < 2^{a+b}
4. 3 \mid q(2^a-q)(2^{a+b}-q(2^a-q))

三、SQIsign2D2的核心创新

3.1 参数重构：p = C \cdot D - 1 with C \approx D \approx \sqrt{p}

核心洞察：传统SQIsign2D变体使用p = f \cdot 2^a - 1，仅利用2的幂次光滑同源。本文提出：

p = 2^{e_2} \cdot 3^{e_3} - 1, \quad \text{其中 } C = 3^{e_3} \approx D = 2^{e_2} \approx \sqrt{p}

关键性质：
- E_0[C] \subset E_0(\mathbb{F}{p^2})且E_0[D] \subset E_0(\mathbb{F}{p^2})（满挠子群有理性）
- C-同源和D-同源均可高效计算（Velu公式，一维）
- 二维同源的度数需求从\sim p降至\sim \sqrt{p}

安全性参数（NIST-I）：
p = 2^{131} \cdot 3^{78} - 1, \quad |p| \approx 256 \text{ bits}

3.2 算法一：ImRanIso（改进随机同源生成）

应用场景：密钥生成（从E_0生成随机同源）

算法流程（Algorithm 1）：

```
输入：整数$d$（目标同源度数，$d < p^{1/4}$，$\gcd(d, CD) = 1$），
      光滑参数$C, D, D' = 2^{\lfloor e_2/2 \rfloor}$
输出：随机$d$-同源$\iota: E_0 \to E$，像点集$\iota(S)$，对应理想$I_\iota$

1. 选取$\{P_0, Q_0\}$为$E_0[D]$的典范基
2. $\theta \leftarrow \text{FullRepresentInteger}_{\mathcal{O}_0}(d(D/D' - d) \cdot C \cdot D')$
   // 构造度数为$d(D/D'-d)CD' > p$的内自同态
3. $I_\varphi \leftarrow \mathcal{O}_0\langle \theta, CD' \rangle$
   // 生成左理想，对应$CD'$-同源
4. 计算$\varphi: E_0 \to E'$，核为$E[I_\varphi]$
5. $(E; \iota(S); \emptyset) \leftarrow \text{KaniCod}(d, D/D' - d, E_0, E',$
   $[D']P_0, [D']Q_0, [1/C]\circ\varphi\circ\theta(P_0), [1/C]\circ\varphi\circ\theta(Q_0); S; \emptyset)$
   // 通过$(D/D', D/D')$-二维同源分解得到$d$-同源
6. $I_\iota \leftarrow \mathcal{O}_0(\theta, d)$
7. 返回$E, \iota(S), I_\iota$
```

关键等式验证：
\varphi \circ \theta = [CD'] \circ \psi \implies \psi([D']P_0) = [1/C] \circ \varphi \circ \theta(P_0)

复杂度对比：

算法	一维同源链长	二维同源链长	总复杂度	
RandIsogImg [27]	0	\sim \log_2 p（度数p）	O(\log p)维2	
RanIso [8]	\sim \frac{1}{2}\log_2 p	\sim \log_2 p	混合	
ImRanIso	\sim \frac{3}{4}\log_2 p	\sim \frac{1}{2}\log_2 p（度数\sqrt{p}）	最优	

实现细节（Remark 1）：
- 若\theta被2或3整除，需迭代除尽以保证理想对应循环同源
- 若除尽后度数不足，可补充随机3-同源链
- 该优化反而提升性能（缩短3-同源链长度）

3.3 算法二：GenImRanIso（广义改进随机同源）

应用场景：签名阶段生成辅助同源（从E_A生成随机同源）

核心挑战：E_A的 endomorphism ring 未知（仅知连接E_0 \to E_A的N\tau-同源\tau）

技术路线（Algorithm 2）：

```
输入：$N_\tau$-同源$\tau: E_0 \to E_A$及其理想$I_\tau$，
      目标度数$d \approx \sqrt{p}$，光滑参数$C, C' \mid C, D$
输出：随机$d$-同源$\iota: E_A \to E_\iota$及像点集

1. 选取$\{P, Q\}$为$E[D]$的典范基
2. $(C_0 : D_0) \leftarrow \text{EichlerModConstraint}(I_\tau, 1, 1)$
   // 在Eichler序$\mathfrak{D} = \mathbb{Z} + I_\tau$中求解模约束
3. $\alpha \leftarrow \text{FullStrongApproximation}_{d(D-d)CC'}(N_\tau, C_0, D_0)$
   // 构造范数$d(D-d)CC' > pN_\tau^3 \approx p^{7/4}$的$\alpha \in \mathfrak{D}$
4. 计算推前理想：
   $I_{\varphi_1} \leftarrow [I_\tau]_* \mathcal{O}_0\langle \alpha, C' \rangle$
   $I_{\varphi_2} \leftarrow [I_\tau]_* \mathcal{O}_0\langle \bar{\alpha}, C \rangle$
5. 计算$C'$-同源$\varphi_1: E \to E_1$和$C$-同源$\varphi_2: E \to E_2$
6. 通过KaniCod计算$(D,D)$-二维同源，得到$d$-同源$\iota': E_1 \to E'$
7. 拉回$\iota = [\varphi_1]^* \iota'$，返回结果
```

关键创新：
- 利用Eichler序\mathfrak{D} = \mathbb{Z} + I\tau构造 endomorphism（而非完整最大序）
- 完全避免(2^e, 2^e)-二维同源（East需要）
- 一维同源承担主要计算量

复杂度对比（表2）：

算法	一维同源度数	二维同源度数	
AuxiliaryPath [29]	0	\sim p^{3/2}（(2^e, 2^e)-同源）	
GenImRanIso	\sim p^{3/2}（光滑一维）	\sim p（(D,D)-同源）	

3.4 协议适配：D-adequate响应同源

定义3.1（D-adequate）整数q是D-adequate若：
1. q为奇数
2. q < D
3. 3 \nmid q

与East的区别：
- East要求(2^a, 2^b)3-nice（含条件3 \mid M(q)）
- 本文仅需D-adequate，移除了3 \mid q(2^a-q)(2^{a+b}-q(2^a-q))的复杂条件

合理性：
- 原条件是为抵抗Castryck等人的密钥恢复攻击[11]
- 本文通过要求\left(\frac{3}{N\tau}\right) = -1（即3为非二次剩余模N\tau）已提供保护
- 简化条件使采样成功率从\sim 1/8提升至\sim 1/4

失败概率控制（第4.3节）：
\Pr[\text{无D-adequate } q] = \left(\frac{3}{4}\right)^{\pi^2 D/C} \approx \left(\frac{3}{4}\right)^{\pi^2 \cdot 3^{e_3}/2^{e_2}}

当C \approx D时，该概率可忽略。必要时可采用gcd-trick[11]进一步提升。

4.1 参数设置（Setup）

安全级别	素数p	e_2	e_3	公钥大小	签名大小

4.2 密钥生成（Algorithm 3）

```
1. 选取随机素数$N_\tau < p^{1/4}$满足$\left(\frac{3}{N_\tau}\right) = -1$
2. $(E_A, \{\tau(P_C), \tau(Q_C), \tau(P_D), \tau(Q_D)\}, I_\tau) \leftarrow \text{ImRanIso}_{\mathcal{O}_0}(N_\tau, 0, D, D', \{P_C, Q_C, P_D, Q_D\})$
3. 返回公钥$pk = E_A$，私钥$sk = (I_\tau, N_\tau, \tau(P_C), \tau(Q_C), \tau(P_D), \tau(Q_D))$
```

4.3 承诺阶段（Algorithm 4）

```
1. 选取随机整数$N_\psi < D \approx \sqrt{p}$，$\gcd(N_\psi, CD) = 1$
2. $(E_1, \{\psi(P_D), \psi(Q_D)\}, I_\psi) \leftarrow \text{ImRanIso}_{\mathcal{O}_0}(N_\psi, C, D, 1, \{P_D, Q_D\})$
3. 发送承诺曲线$E_1$
```

安全性假设（Assumption 1）：ImRanIso输出的E_1与随机超奇异曲线计算不可区分。

4.4 挑战与响应

挑战（Algorithm 5）：验证者发送K{\text{cha}} = P{\text{cha}} + [c]Q{\text{cha}} \in E_1[C]，其中c \xleftarrow{\$} \mathbb{Z}/C\mathbb{Z}。

响应（Algorithm 6）：

```
1. 计算挑战同源$\varphi: E_1 \to E_2$，核$\langle K_{\text{cha}} \rangle$
2. $I_\varphi \leftarrow \text{IsogenyToIdeal}(\varphi, \psi, I_\psi)$
3. 重复：
   $J \leftarrow I_\tau I_\psi I_\varphi$
   $I_\sigma = J\frac{\alpha}{\text{Nrd}(J)} \leftarrow \text{RandomEquivalentIdeal}_D(J)$
   $q \leftarrow \text{Nrd}(J)$
   直到$q$为D-adequate
4. 计算典范基$\{P_A, Q_A\}$ of $E_A[D]$，求值$\sigma(P_A), \sigma(Q_A)$
5. $d \leftarrow D - q$
6. 若$\left(\frac{d(D-d)}{N_\tau}\right) = \left(\frac{-1}{N_\tau}\right)$：
      $E_{\text{aux}}, \{R_{\text{aux}}, S_{\text{aux}}\} \leftarrow \text{GenImRanIso}_{\tau, I_\tau}(d, C, C, D, \{P_A, Q_A\})$
   否则：
      $E_{\text{aux}}, \{R_{\text{aux}}, S_{\text{aux}}\} \leftarrow \text{GenImRanIso}_{\tau, I_\tau}(d, C, C/3, D, \{P_A, Q_A\})$
7. 计算矩阵$M$使得$(P_{\text{aux}}, Q_{\text{aux}}) = (R_{\text{aux}}, S_{\text{aux}})M$
8. $(U_2, V_2) = -(\sigma(P_A), \sigma(Q_A))M$
9. 返回$(E_{\text{aux}}, \{U_2, V_2\})$
```

Legendre符号条件的意义（Remark 4）：确保FullStrongApproximation有解，等价于要求
\left(\frac{d(D-d)CC'}{N\tau}\right) = \left(\frac{-1}{N\tau}\right)

4.5 验证（Algorithm 7）

```
1. 计算$E_{\text{aux}}[D]$的典范基$\{P_{\text{aux}}, Q_{\text{aux}}\}$
2. 计算$(D,D)$-同源$\Phi: E_{\text{aux}} \times E_2 \to A$，核$\langle (P_{\text{aux}}, U_2), (Q_{\text{aux}}, V_2) \rangle$
3. 若$A \cong E_A \times E_3$或$E_3 \times E_A$：
      分解出$\hat{\sigma}: E_2 \to E_A$
      若$\deg(\hat{\sigma})$为D-adequate，接受；否则拒绝
   否则拒绝
```

五、安全性分析

5.1 特殊可靠性（Special Soundness）

定理5.1（Theorem 2）：SQIsign2D2识别协议具有特殊可靠性。

证明概要：
给定两个有效对话(E_1, K{\text{cha}}, E{\text{aux}}, U_2, V_2)和(E_1, K'{\text{cha}}, E'{\text{aux}}, U'2, V'2)，其中\langle K{\text{cha}} \rangle \neq \langle K'{\text{cha}} \rangle：

1. 揭示挑战同源\varphi: E_1 \to E_2和\varphi': E_1 \to E'2
2. 恢复响应同源\sigma: E_A \to E_2和\sigma': E_A \to E'2
3. 构造 endomorphism \alpha = \hat{\sigma}' \circ \varphi' \circ \hat{\varphi} \circ \sigma \in \text{End}(E_A)

非平凡性证明：若\alpha = [n]为标量乘法，则\alpha(P) = \infty对所有P \in E[C]成立。但\gcd(q, C) = \gcd(q', C) = 1，故\varphi' \circ \hat{\varphi} = [C]，即\ker(\varphi) = \ker(\varphi')，矛盾。

5.2 零知识性（Zero-Knowledge）

定义5.2（RUADIO）：随机均匀D-adequate同源预言机，输入E输出(\sigma(P), \sigma(Q))，其中\sigma: E \to E'为随机D-adequate同源。

定义5.3（FIDIO）：固定度数同源预言机，输入(E, N)输出(\varphi{\text{aux}}(P), \varphi{\text{aux}}(Q))，其中\varphi{\text{aux}}: E \to E'为随机N-同源。

困难问题（Problem 1）：区分以下两种分布：
1. 采样q \sim \mathcal{Q}，然后从\mathcal{U}{\text{Iso}(E_A, q)}（均匀D-adequate同源）采样\varphi{\text{aux}}
2. 采样q \sim \mathcal{Q}，然后从GenImRanIso输出分布采样\varphi{\text{aux}}

定理5.4（Theorem 3）：若承诺曲线E_1与随机超奇异曲线计算不可区分，且Problem 1困难，则SQIsign2D2在RUADIO+FIDIO模型下是特殊诚实验证者零知识的。

5.3 承诺采样强化（第5.3节）

针对Assumption 1的两种强化方案：

方案一：Double Path技术（来自SQIsignHD[15]）
- 计算 endomorphism \gamma of degree C'^2 D'^2
- 分解为两条路径：\psi_1（C'^2-同源）和\psi_2（D'^2-同源）
- 承诺同源度数提升至\sim p，增强随机性
- 代价：额外计算，但仍保持高效

方案二：(3,3)-同源适配
- 直接计算(CD, CD)-二维同源
- 利用p+1 = CD的因数分解
- 当前(3,3)-同源实现效率较低，有待优化

七、个人思考与展望

7.1 量子信息科学视角的解读

作为量子信息科学专业的学生，我认为本文的核心贡献在于经典-量子计算边界的精细刻画：

1. 同源问题的量子复杂性

Shor算法破解RSA/ECC的关键在于隐藏子群问题（HSP）在阿贝尔群上的高效量子求解。然而，超奇异同源问题对应非阿贝尔群（四元数代数理想类群），目前无已知量子算法能突破经典复杂度。

本文通过一维光滑同源降低计算开销，这一策略的量子安全性基于：
- 一维光滑同源：经典高效（Velu公式），量子无显著加速
- 二维同源：经典瓶颈，量子亦无多项式算法

关键问题：是否存在量子算法能加速Kani引理中的二维同源计算？这涉及高维阿贝尔簇上的量子游走，目前研究空白。

2. 参数设计的量子启示

本文参数p = 2^{e_2}3^{e_3} - 1的选择体现了量子计算资源的不对称性：
- 量子傅里叶变换对2的幂次有天然优势
- 但3-同源的经典计算已足够高效，无需量子优化
- 这种"经典-量子混合"设计可能适用于其他密码构造

7.2 对论文的批判性思考

优势：
1. 算法工程化程度高：完整Julia实现，实验数据详实
2. 问题定位准确：精准识别二维同源为瓶颈，而非盲目优化
3. 理论-实践平衡：在安全性假设与效率间取得较好权衡

潜在局限：

1. 承诺生成的启发式假设

Assumption 1（ImRanIso输出随机性）缺乏严格证明。虽然第5.3节提出两种强化方案，但：
- Double Path增加计算开销
- (3,3)-同源当前实现不成熟

建议改进：能否借鉴可证明安全承诺技术，如利用延迟加密（delay encryption）或时间锁谜题强制计算随机性？

2. 与格密码的竞争力

即使2.6×加速，SQIsign2D2的签名时间（587ms）仍远高于ML-DSA（<1ms）。其优势在于签名长度（154B vs 2420B）。

开放问题：在5G/IoT等带宽受限场景，签名长度vs计算时间的权衡如何量化？需要全栈安全评估（包括网络延迟、电池消耗等）。

3. 量子实现的探索

本文完全聚焦经典优化，但未探讨：
- 量子模拟：小规模量子计算机能否加速内自同态搜索？
- 量子-经典混合协议：类似TLS 1.3的混合模式，同源+格双重保护

7.3 未来研究方向

短期（1-2年）：
1. 进一步优化(3,3)-同源实现，使第5.3节的强化方案实用化
2. GPU/FPGA加速，特别是KaniCod的并行化
3. 形式化验证，确保Julia实现的常数时间安全性

中期（3-5年）：
4. 量子算法研究：探索超奇异同源问题的量子查询复杂度下界
5. 与其他后量子方案的混合协议：同源+格、同源+编码等
6. 后量子TLS/SSH集成：解决证书链长度、握手延迟等工程问题

长期（5年以上）：
7. 容错量子计算时代的密码学：当Shor算法真正可行时，同源密码是否仍安全？这需要量子复杂性理论的突破，特别是非阿贝尔HSP的量子难度证明。

---

八、结论

SQIsign2D2通过参数重构（p = CD-1）和算法创新（ImRanIso/GenImRanIso），将SQIsign2D家族的效率提升至新高度。其核心洞见——用一维光滑同源替代高维同源计算——不仅具有直接的工程价值，也为后量子密码学的经典-量子资源权衡提供了新范式。

作为量子信息科学专业的学生，我认为本文最重要的启示在于：量子安全不等于量子低效。通过精细的算法设计，完全可以在保持抗量子安全性的同时，实现可实用的计算效率。这一"经典优化为主、量子安全为基"的思路，可能适用于更广泛的密码学构造。
